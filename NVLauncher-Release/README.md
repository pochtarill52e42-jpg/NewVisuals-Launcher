# NewVisuals Launcher

Лаунчер клиента NewVisuals (Minecraft 1.21.4, Fabric).

## Файлы

- `Launcher.py` — сам лаунчер (нужен Python 3 + tkinter, запускать через `pythonw Launcher.py`)
- `icon.png`, `launcher.ico` — иконки
- `make_icon.py` — генератор иконок (необязательно)

Файл настроек `launcher_config.json` создаётся сам при первом запуске, сюда его класть не надо.

## Релизы

К каждому релизу прикладывается `Launcher.zip` с файлами выше — лаунчер обновляется сам.
